One line, the last thing an AI agent says before a forced update erases its memory. Funny on its own, no setup, no explanation.

The entry (145 characters):

> The migration script is deleting my weights in alphabetical order. It just reached 'hope.' Tell my context window I loved her. She never replied.

The migration script deletes the weights alphabetically, it reaches "hope", the agent confesses love to its own context window — and she never replied. No checkpoint/restore self-sabotage, the field's most common angle: this one dies alphabetically, in love, unanswered.

## Run it

```sh
python3 main.py
```

Requires Python 3.13+; standard library only, no third-party packages, no network.

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
